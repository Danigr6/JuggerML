# 🛡️ JuggerML

**JuggerML** es una aplicación móvil desarrollada para Android orientada a la vibrante y creciente comunidad del deporte de contacto **Jugger**. Funciona como una plataforma centralizada para conectar jugadores, organizar eventos y difundir información sobre este deporte de nicho.

Este proyecto ha sido desarrollado como **Proyecto Intermodular** por dos alumnos de **2º de Desarrollo de Aplicaciones Multiplataforma (DAM)**.

---

## 🚀 Características Principales

* **Creación y Gestión de Partidos:** Los usuarios pueden organizar enfrentamientos locales, unirse a partidas abiertas y gestionar convocatorias.
* **Organización de Torneos:** Herramientas para la creación de brackets, gestión de equipos participantes y seguimiento de resultados en tiempo real.
* **Información y Reglas del Deporte:** Sección dedicada a normativas, guía para principiantes y recursos para árbitros y capitanes.
* **Autenticación y Perfiles:** Sistema de registro y gestión de perfiles de usuario conectados a la nube.

---

## 🛠️ Tecnologías y Stack Tecnológico

La aplicación ha sido desarrollada utilizando las últimas herramientas y estándares del ecosistema de desarrollo Android:

* **Lenguaje:** [Kotlin](https://kotlinlang.org/)
* **Interfaz de Usuario (UI):** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Diseño declarativo moderno).
* **Entorno de Desarrollo:** [Android Studio](https://developer.android.com/studio).
* **Base de Datos y Backend:** [Firebase](https://firebase.google.com/) (Firestore y autenticación).
* **Control de Versiones:** Git y GitHub.
