# JuggerML 🤾‍♂️⚡

**JuggerML** es una aplicación móvil desarrollada en **Kotlin** con **Jetpack Compose**, diseñada como proyecto académico para el 2º curso del Grado Superior de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## 👨‍💻 Autores

Este proyecto ha sido desarrollado por:

* **Daniel García Rodríguez**
* **Abel Jaen Mora**

## 📌 Descripción del Proyecto

JuggerML nace con el objetivo de ofrecer una solución moderna, intuitiva y funcional enfocada en la gestión, seguimiento o experiencia relacionada con el deporte del **Jugger** (o la temática principal de la app). La aplicación aprovecha al máximo las capacidades del desarrollo nativo en Android mediante arquitecturas modernas y componentes de interfaz declarativa.

## 🛠️ Tecnologías y Herramientas

* **Lenguaje:** [Kotlin](https://kotlinlang.org/)
* **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Interfaz declarativa)
* **Arquitectura:** MVVM (Model-View-ViewModel) 
* **Navegación:** Jetpack Compose Navigation
* **Persistencia de Datos:** Room*
* **Mínimo SDK:** API Level 24 (Android 7.0) o superior

## ✨ Características Principales

* **Interfaz Moderna e Intuitiva:** Diseñada siguiendo los lineamientos de *Material Design 3*.
* **Rendimiento Nativo:** Optimizado gracias a la compilación eficiente de Jetpack Compose y Kotlin.
* **Soporte Tema Claro/Oscuro:** Adaptación automática al sistema o preferencia del usuario.
